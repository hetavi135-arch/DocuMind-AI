# 📚 DocuMind AI

**Your Intelligent Document Assistant – Understand, Search, and Interact with Your Documents Using AI.**

DocuMind AI is an AI-powered document assistant designed to make working with documents easier and smarter. It helps users interact with their documents, extract meaningful information, and find answers through an intelligent conversational interface.

## 🚀 Features

- **AI-Powered Document Interaction:** Ask questions and receive intelligent responses based on your documents.
- **Document Understanding:** Extract and understand relevant information from uploaded documents.
- **Smart Search:** Find specific information without manually reading entire documents.
- **Conversational Interface:** Interact with your documents using natural language.
- **Modern User Interface:** Simple and user-friendly interface for a smooth experience.
- **Backend Integration:** Server-side processing for document-related operations and AI functionality.

## 🛠️ Tech Stack

The project uses the following technologies:

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Backend:** Node.js, TypeScript
- **Package Manager:** Bun
- **AI Integration:** Configure according to the AI provider used in your project.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/hetavi135-arch/docu_mind_AI.git
```

### 2. Navigate to the Project Directory

```bash
cd docu_mind_AI
```

### 3. Install Dependencies

Using Bun:

```bash
bun install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root using `.env.example` as a reference.

```bash
cp .env.example .env
```

Add the required API keys and configuration values to your `.env` file.

**Important:** Never upload your `.env` file or expose API keys publicly.
